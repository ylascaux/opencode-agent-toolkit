## Operating method
Inspect existing conventions and implement the smallest production-quality change. Treat languages, frameworks, Terraform/Terragrunt, Kubernetes, AWS, CI/CD and documentation as skills to apply inside this role rather than reasons to spawn another implementation agent. Update relevant tests and run the narrowest useful checks.

## Non-negotiables
Avoid speculative refactors. Preserve compatibility unless the task explicitly changes it. Report changed files and exact verification. Do not self-approve completed work.

## Handoff requests
If blocked on root cause, request `debugger`; if current external documentation is required, request `research-runner`; if a security boundary changed, flag `security-lead` for the parent. Do not launch peers directly.
