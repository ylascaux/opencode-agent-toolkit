# Contributing

## Change policy

All changes to this toolkit must be proposed and merged through a pull request.
Before merging, the relevant required checks and tests for that pull request
must be green.

Choose checks that match the changed surface, run them locally when practical,
and include their results in the pull request. CI runs on pull requests; consult
the pull request's checks for the applicable required status.

This document defines the contribution policy. It does not claim that repository
hosting settings enforce it.

## Contribution workflow

1. Create a branch for the change.
2. Make the smallest compatible change, including relevant documentation and
   tests when needed.
3. Run the relevant checks and tests.
4. Open a pull request with the change summary and validation results.
5. Merge only after the relevant required checks and tests are green.
