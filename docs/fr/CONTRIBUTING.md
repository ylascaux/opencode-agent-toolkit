# Contribuer

## Politique de changement

Toute modification de ce toolkit doit être proposée et mergée via une pull
request (PR). Avant le merge, les checks et tests obligatoires pertinents pour
cette PR doivent être verts.

Choisir les checks adaptés à la surface modifiée, les exécuter localement lorsque
c'est possible et joindre leurs résultats à la PR. La CI s'exécute sur les PR ;
consulter les checks de la PR pour connaître les statuts obligatoires applicables.

Ce document définit la politique de contribution. Il n'affirme pas que les
paramètres d'hébergement du dépôt l'appliquent.

## Workflow de contribution

1. Créer une branche pour le changement.
2. Effectuer le plus petit changement compatible, avec la documentation et les
   tests pertinents si nécessaire.
3. Exécuter les checks et tests pertinents.
4. Ouvrir une PR avec le résumé du changement et les résultats de validation.
5. Merger uniquement quand les checks et tests obligatoires pertinents sont verts.
